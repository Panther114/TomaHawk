## 这是什么

战斧是一款纯本地运行的现代联合作战推演工具：你在地图上部署水面、水下、地面与空中单位，按下播放后，双方指挥 AI 只依据各自传感器探测到、并共享的航迹自主行动——探测、跟踪、发射、拦截、损伤与弹药消耗都在实时发生。

**确定性**：相同的地图、种子与操作，永远得到相同的结果。**纯本地**：没有后端、没有账号、没有隐藏逻辑，推演、存档与自定义单位全部在你的浏览器里完成。

![推演沙盘](docs/screenshots/sandbox-battle.png)

*推演进行中：雷达扫描、航迹共享、导弹拦截与弹药消耗实时上演。*

## 快速开始

需要 Node.js 20 或更高版本，无需安装任何依赖：

```bash
npm start
```

然后打开 <http://127.0.0.1:4202>：

| 页面 | 说明 |
| --- | --- |
| `/` | 产品首页 |
| `/sandbox` | 推演沙盘（建议桌面浏览器，内容区至少 960×560） |
| `/guide` | 交互式操作手册 |

**新手先打开 `/guide`。** 它不是图文教程，而是一个全屏沉浸式教学台：真实沙盘铺满整个屏幕，金色的光标提示会指向你下一步要点击的位置，每一步只允许操作当前目标，完成操作后自动进入下一步——大约 5 分钟，你就能在正式界面上亲手完成部署、运行、判读与保存。

![交互式操作手册](docs/screenshots/guide-tutorial.png)

## 怎么玩

1. 打开沙盘，点击左上角「部署兵力」，为蓝方选择一艘驱逐舰
2. 把光标移到海面上，轮廓变蓝后单击放置；再为红方部署一支兵力（悬停装备卡，点击右侧红色半区）
3. 点击底部 ▶ 开始推演，用速度滑杆调速，`Space` 随时暂停
4. 点选地图上的单位，在右侧查看生命、任务与剩余弹药
5. 需要长期保存？右下角系统工具 →「保存推演」

## 技术栈

- **纯前端**：HTML / CSS / JavaScript（ES Modules），零构建、零运行时依赖
- **Canvas 2D** 战术地图渲染 + 轻量 DOM HUD
- **Node.js** 静态服务器（Railway 一键部署）
- **Playwright** 驱动的自动化回归测试
- **确定性仿真核心** `src/sim/`：DOM 无关，可直接在 Node 中运行与测试

## 特性

- 联合作战单位：水面舰艇、潜艇、地面阵地、机场与航空兵编队
- 传感器与航迹：雷达、声呐、ESM、雷达地平线、RCS、航迹老化与跨单位共享
- 协同交战（CEC）：共享目标火力与超视距拦截
- 分层防空、近防、反舰、对陆打击、反潜与高超音速攻防
- 航空后勤：燃油、返航、再装填、航母甲板与机场支援
- 电子对抗：电子攻击、烧穿、反辐射压制与软杀伤
- 子系统损伤、编组损耗与弹药耗尽
- 本地单位工坊：自定义单位并保存进装备库

![产品首页](docs/screenshots/landing.png)

战斧不是经过验证的任务规划或作战分析工具，也不建模雷场、后勤、天气海况与人员训练；公开装备参数为基于公开资料的工程抽象。

## 项目结构

- `sandbox.html` + `src/app.js` — 推演沙盘界面（画布渲染与交互）
- `guide.html` + `src/guide.js` — 交互式操作手册（内嵌真实沙盘的教程引擎）
- `src/sim/` — 确定性仿真核心
- `src/mods/` — 单位工坊与本地存储
- `server.mjs` — 轻量静态文件服务器
- `tests/` — 规则、持久化、UI 与性能回归测试
